TritRuntime —— tModLoader 旁路三进制运行时改善层。

这个模组不替换 tModLoader 的 C# / CLR / Unity 主循环。它只做三件事：

1. 通过 Terraria.On_* 钩子（只观测，不回写）把 NPC / Projectile / Player 的每 tick 状态变化
   投影成三进制车道（-1 减少 / 0 不变 / +1 增加）。
2. 把这些变化作为事务意图提交给三进制运行时内核：跨事务仲裁 -> 只追加事务日志 ->
   Step() 触发事件路由派发 -> 周期性快照与差分。
3. 通过 Mod.Call("TritRuntime.*") 把同一套内核能力暴露给其他模组。

原生 Rust 内核（trit_rt.dll）存在时优先使用；缺失 / ABI 不符 / 装载失败时自动回退到
语义逐字节等价的托管内核，绝不向调用方抛异常。切换前可用影子模式对同一请求序列做
逐字节差分：不一致只记录不提交。

所有游戏状态读写都在 C# 主线程完成。原生内核只接触纯数据与句柄。
